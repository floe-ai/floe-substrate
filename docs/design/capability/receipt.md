# Receipt

_Resolution: settled_
_Built: partly_
_Authority: agent-provisional_
_Authored by: unknown_

Canonical name: **Operation receipt.** The stable result of one idempotent
operation call. It records principal, exact target and revision, provenance,
state, changed references, refusal or required action, and progress and cancel
references. A client reconnects to the receipt instead of guessing whether an
operation committed.
