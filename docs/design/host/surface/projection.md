# Projection

_Resolution: settled_
_Built: yes_
_Authority: agent-provisional_
_Authored by: unknown_

A read-only, queryable view derived from canonical records, for surfaces to
show. Organised work, Scope plan and execution, Artefact lineage, Context trees,
attention, health and current heads are projections. A projection is never
another ledger.

A chat shows selected Context Events and collaboration state. A Scope view shows
one published revision and its execution records. An Artefact view shows exact
version provenance. A surface may add interaction and presentation, but never
infers topology from activity.

Surfaces project and invoke the same Bus-owned operations
([Capability](../../capability/capability.md)); they do not own parallel
validation or policy. Developer diagnostics may expose raw evidence, but normal
operator work never depends on developer tools.
