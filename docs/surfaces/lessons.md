# Lessons

These docs improve each time a surface is built.

At the end of surface work, list what would have saved time or prevented a
mistake: a missing rule, an unclear step, a pattern that worked. For each one,
draft the exact edit to `docs/surfaces/`.

Give the drafts to the operator. If approved, they are applied on a Floe branch
and merged with approval like any other Floe change.

Only lessons about building any surface belong here. Lessons about one product
stay in that product's repository.
